# Gia Phả Web

Ứng dụng web Gia phả dòng họ phát triển bằng **React 19**, **Vite 8**, **Tailwind CSS v4** và **TypeScript**.

👉 Xem tài liệu hướng dẫn chi tiết tại: [HUONG_DAN.md](file:///d:/MY%20PRO/applications/GiaPha/web/HUONG_DAN.md)

## Bắt Đầu Nhanh

```bash
# 1. Cài đặt thư viện
pnpm install

# 2. Khởi chạy môi trường phát triển
pnpm dev

# 3. Kiểm tra kiểu TypeScript
pnpm exec tsc --noEmit

# 4. Build sản phẩm
pnpm build
```

Mở trình duyệt tại: **http://localhost:8443**
